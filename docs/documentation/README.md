## 🤝 Como Contribuir

### Reportando Erros

Encontrou um erro ou informação desatualizada?

1. Abra uma issue: [GitHub Issues](https://github.com/kcshub/documentation/issues)
2. Descreva o problema
3. Cite a página e linha (se possível)

### Sugerindo Melhorias

Tem uma sugestão para melhorar a documentação?

1. Abra uma discussão: [GitHub Discussions](https://github.com/kcshub/documentation/discussions)
2. Descreva a melhoria
3. Explique o contexto

### Enviando Conteúdo (Pull Requests)

Se quer contribuir com novas páginas:

1. Clone o repositório
2. Crie uma branch: `feature/nova-pagina`
3. Use [PAGE_TEMPLATE.md](08-reference/PAGE_TEMPLATE.md) como base
4. Siga [STYLE_GUIDE.md](08-reference/STYLE_GUIDE.md)
5. Envie PR com descrição clara
6. Aguarde revisão

## 🛠️ Ferramentas Recomendadas

### Para Ler Documentação

- **Web:** GitHub Pages (renderização nativa de Markdown)
- **Local:** VS Code (com extensão Markdown Preview)
- **Offline:** Markdown viewers (Typora, Obsidian, etc.)

### Para Editar

- **Recomendado:** VS Code + Markdown All in One extension
- **Alternativa:** GitHub web editor (direto no navegador)
- **Para Produção:** GitBook, Docusaurus, ou MkDocs

### Para Publicar Profissionalmente

| Ferramenta | Use quando... | Custo |
|-----------|---|---|
| **GitBook** | Quer visual profissional com pouco setup | $12+/mês |
| **Docusaurus** | Prefere self-hosted com controle total | Grátis (self-hosted) |
| **ReadTheDocs** | Integração direta com GitHub/GitLab | Grátis |
| **Notion** | Prefere gerenciamento visual e colaboração | $8+/mês |
